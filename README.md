# 発表タイマー（Web版）

設計仕様書 Ver.2.2 に基づく実装です。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | 表示パネル・操作ボタン・設定パネルのDOM構造 |
| `style.css` | レイアウト、表示色、スケール連動サイズ |
| `script.js` | 状態管理、タイマー処理、鳴動判定、リサイズ処理 |
| `chime1.wav` | 1鈴用の音声（卓上ベル音1回） |
| `chime2.wav` | 2鈴用の音声（卓上ベル音2回） |
| `chime3.wav` | 3鈴用の音声（卓上ベル音3回） |

## 使い方

6ファイル（`index.html`・`style.css`・`script.js`・`chime1.wav`・`chime2.wav`・`chime3.wav`）を同じフォルダに置き、`index.html` をブラウザで開いてください。サーバーは不要です。

1. 設定パネルで発表時間・質疑応答時間・内部討議時間を入力します
2. 使わないモードは、各設定ブロック右上の **使用する** のチェックを外します（1つ以上は有効にする必要があります）。無効なモードは、モードの切替・表示・鈴の動作のすべてから外れ、設定欄は灰色になります。有効モードが1つだけの場合は **モード** ボタンが押せなくなります
3. 予鈴・終鈴を使う場合はチェックを入れ、鳴らす秒数と鈴種を選びます
4. **設定反映** を押すと設定が確定し、最初の有効モード（通常は発表）の設定時間が表示されます
5. **開始** で計測開始、**停止** で一時停止、**モード** で 発表 → 質疑応答 → 内部討議 の順に切替、**リセット** で設定時間に戻ります

表示パネル下の **モード名を表示** のチェックを外すと、モード名（発表・質疑応答・内部討議）の表示を消せます。このとき表示パネルの大きさは変わらず、時間表示が縦中央に表示されます。設定反映を押さなくても、すぐに切り替わります。

表示パネル（黒い領域）の右下角をドラッグすると、タイマー表示とモード名の大きさを変えられます（0.5〜3.0倍）。操作ボタンと設定パネルの大きさは変わりません。

## 表示色

| モード | 通常 | 超過中 |
|---|---|---|
| 発表 | 緑 `#5AFF07` | 赤 `#F80201` |
| 質疑応答 | 黄 `#FEFF15` | 赤 `#F80201` |
| 内部討議 | 水色 `#19D3FF` | 赤 `#F80201` |

タイマー表示とその直下のモード名表示は、常に同じ色で表示されます。

## 鈴の音を変更する

同梱の `chime1.wav` / `chime2.wav` / `chime3.wav` は動作確認用の合成音です。
**同じファイル名のまま**お好みの音声ファイルに差し替えれば、スクリプトを変更せずに音を変えられます。

ファイル名自体を変更したい場合は、`script.js` 冒頭の定数1か所だけを修正してください。

```javascript
const BELL_SOUND_FILES = {
  1: 'chime1.wav',   // 1鈴
  2: 'chime2.wav',   // 2鈴
  3: 'chime3.wav'    // 3鈴
};
```

予鈴1・予鈴2・終鈴はこの3ファイルを共通で使用し、選択した鈴種によって再生するファイルが決まります。

## 表示の大きさの初期値を変える

`script.js` の以下の定数を変更してください。

```javascript
const BASE_PANEL_WIDTH = 1000;  // 基準幅(px)。style.css の #displayPanel の 1000px も同じ値に揃えること
const SCALE_MIN = 0.5;          // 最小倍率
const SCALE_MAX = 3.0;          // 最大倍率
```

## 補足

- ブラウザの自動再生制限のため、鈴の音は最初にいずれかのボタンを押した後から鳴ります
- 設定値・表示サイズはページを再読み込みすると初期値に戻ります（仕様書の対象範囲外）
